# The Rajmahal — Royal Wedding Invitation Template 👑

A pixel-perfect clone of **The Rajmahal** wedding invitation template (`https://www.jointhejashn.com/demo/rajmahal`).

---

## ✨ Features

- 🏛️ **Royal 3D Gate Open Experience**: Gate scene with 3D perspective opening doors powered by GSAP & ScrollTrigger.
- 🌐 **Bilingual (English & Hindi) Toggle**: Live language switching across all sections with native typography.
- ⏳ **Interactive Live Muhurat Countdown**: Days, Hours, Minutes, Seconds counting down to the wedding date with gold shimmer effect.
- 🦚 **Royal Palace & Peacock Illustrations**: All original assets, toran, jharokha, elephants, and palace artwork.
- 📜 **Interactive Story Timeline**: Golden progress indicator line filling on scroll.
- 📅 **Celebration Events Schedule**: Haldi, Mehendi, Sangeet, The Wedding, and Reception with 1-click Google Calendar integration.
- 🖼️ **Arched Photo Gallery**: Arched frame photo cards with hover micro-animations.
- 📍 **Venue & Location Cards**: Location details with interactive Map and Directions actions.
- 👨‍👩‍👧‍👦 **Family Members & Lineage**: Royal peacock crest with bride & groom family listings.
- ❓ **FAQ Accordion**: Collapsible interactive questions and answers.
- 💌 **Full RSVP System**:
  - Multi-event attendance toggles
  - Guest counter stepper
  - Form validation with animated royal confirmation card
- 📱 **100% Mobile & Desktop Responsive**: Includes smooth mobile navigation drawer.

## 🚀 How to Run

### Option 1: Direct Double Click
Simply open [`index.html`](file:///C:/Users/Avira/rajmahal-template/index.html) in any browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run Local Development Server
Open terminal in `C:\Users\Avira\rajmahal-template` and run:
```bash
npx serve -l 3000
```
Then visit `http://localhost:3000`.
